# Flowscope

**Network flow analyzer** — talkers, protocol filters, threat tags (suspicious / blocked).

Live demo: **https://kianpk.github.io/flowscope/**

## Stack

Vue 3 · Vite · Express

## Run

```bash
cd server && npm i && node index.js   # :8820
cd client && npm i && npm run dev     # :5190
cd client && npm run build            # → docs/
```

Defensive telemetry UI — demo dataset for Pages; wire to your flow exporter in production.
